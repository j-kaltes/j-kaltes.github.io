This page is independent of Juggluco and should be served over HTTPS. When connecting to a home-network address, a current Chromium browser asks permission to access devices on the local network. Juggluco must also allow this page's Origin. Browsers without that permission feature require an HTTPS Juggluco URL. For a public hostname, use HTTPS for both this page and the Juggluco endpoint; browsers block HTTPS-to-HTTP public connections as mixed content.
